Como testar agora

Passo a passo

  1. Faça download deste repositório ou clique com o botão direito em qualquer lugar desta página.
  2. Escolha "Salvar como..." para guardar o arquivo index.html no seu computador.
  3. Abra o arquivo em qualquer navegador moderno (Chrome, Edge, Safari).
  4. Os dados ficam salvos localmente no seu navegador. Use o botão "Limpar dados" para recomeçar.

Próximos passos sugeridos

  • Conectar formulários à API NestJS quando o backend estiver publicado.
  • Plugar visualizações (Kanban/Gantt) reais usando o componente da aplicação oficial.
  • Criar landing page Next.js com este mesmo conteúdo e analytics.
