# Guia Rápido CultureUP MVP

## 1. Onboarding Inicial (Admin)
1. Acesse `app.cultureup.app` e crie seu workspace (nome + URL personalizada).
2. Convide seu time por e-mail ou importando CSV.
3. Configure espaços:
   - **Operações** → squads/projetos.
   - **Pessoas** → rituais de feedback e 1:1s.
   - **Estratégia** → OKRs.
4. Escolha um template inicial (Sprint, Roadmap, OKR Trimestral, Rituais de Feedback).

## 2. Fluxo de Trabalho Diário
- **Tarefas**: utilize views Tabela/Kanban para priorizar. Campos customizados para status, prioridade, valor estratégico.
- **OKRs**: crie objetivos trimestrais, adicione KRs com métricas ou consultas de tarefas. Vincule listas ou automações.
- **Feedbacks**: envie elogios públicos e feedbacks privados com templates pré-prontos.
- **1:1s**: defina cadência, pauta sugerida e acompanhe follow-ups.

## 4. Recursos de IA (MVP)
- **Gerar tarefa**: digite “Criar playbook de feedback para squad CX” → IA cria tarefa com subtarefas.
- **Resumo de comentários**: selecione discussões extensas → IA sintetiza próximos passos.
- **Pauta 1:1**: informe contexto (ex.: "membro novo") → IA sugere tópicos.
- **Feedback assistido**: escolha tom (positivo, construtivo).

## 5. Integrações
- **Power BI**: exporte datasets de tarefas/OKRs via API e consuma em dashboards.
- **Google/Microsoft**: SSO + sincronização de agenda (1:1s via iCal).
- **Webhooks**: configure automações para Slack/Teams.

## 6. Boas Práticas
- Atualize status de tarefas antes do daily.
- Registre notas de 1:1 imediatamente após a conversa.
- Use tags de valores nos elogios (ex.: “Foco no Cliente”).
- Revise OKRs semanalmente e ajuste pesos/KRs conforme necessidade.
